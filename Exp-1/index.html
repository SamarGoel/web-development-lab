Welcome to My Website!

This is a simple static site hosted using GitHub Pages.

About This Project

This project was created as part of a Web Design practical experiment by Samar Goel. The goal is to learn how to set up a GitHub repository, create and manage branches, merge changes, and deploy a simple static website using GitHub Pages. It demonstrates the basics of version control and web hosting with Git and GitHub.

What I Learned

HTML & CSS

Creating structure and designing attractive webpages using clean HTML and CSS.

GitHub

Creating repositories, managing files and tracking changes using Git workflow.

GitHub Pages

Publishing and hosting static websites online directly from a GitHub repository.
